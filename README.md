# 이용약관에 동의하고 싶어

약관 동의 화면을 테마로 한 고난도 웹 퍼즐 게임입니다.  
단순 체크박스에서 시작하지만, 스크롤 검증·도망가는 버튼·함정 선택지·기억 퍼즐까지 점점 어려워지는 구조로 구성되어 있습니다.

## 배포 주소 (GitHub Pages)

- 👉 [여기를 클릭해 실행](https://mahyun-dev.github.io/agree-game/)

## 게임 설명

- 장르: 웹 퍼즐 + 심리 연출
- 언어: 한국어 UI/텍스트 기반
- 플랫폼: 모바일/데스크톱 반응형 웹
- 플레이 규칙: 실수(오답/시간 초과/함정 선택) 시 처음부터 재시작

## 핵심 특징

- 점진 난이도 상승형 12스테이지
- 스테이지별 제한시간 HUD
- 스크롤 기반 검증, 입력 퍼즐, 버튼 추적, 정렬 퍼즐, 시퀀스 퍼즐
- 시각/청각 연출(글리치, 경고 문구 전환, 진동/사운드)
- 최고 기록 저장(localStorage)
- PWA 지원(manifest, service worker, 홈 화면/데스크톱 설치)
- 오프라인 앱 셸 캐시 및 자동 업데이트 반영

## 스테이지 개요

1. 승인 스위치보드: 짧게 노출되는 패턴과 동일하게 4개 채널 상태를 맞추기
2. 봉인 문서 수색: 9개의 문서 중 진짜 승인 문서를 찾기
3. 싱크 임팩트: 움직이는 마커가 안전 구간에 들어왔을 때만 동기화 성공시키기
4. 파편 문장 복원: 왜곡된 단어 조각을 올바른 순서로 선택하기
5. 동의 두더지: 튀어나오는 동의 버튼만 빠르게 포착하고 거절 함정 피하기
6. 와이어 컷: 보안 와이어를 표시된 순서대로 정확히 절단하기
7. 버튼 미로: 수많은 가짜 버튼 사이에서 진짜 승인 버튼 하나 찾기
8. 트리플 다이얼: 3개의 승인 다이얼을 목표 수치에 동시에 맞추기
9. 팝업 스톰: 팝업 10개를 정리하되 함정 버튼은 누르지 않기
10. 메모리 펄스: 짧게 보여주는 숫자 시퀀스를 기억해 그대로 입력하기
11. 위장 약관: 정상 동의 항목만 골라 미끼 약관을 피하기
12. 오버라이드 씰: 봉인을 순서대로 해제한 뒤 최종 승인 버튼을 추적하기

## 안내

- 본 프로젝트는 게임 연출이며 실제 약관/개인정보 동의와 무관합니다.
- 지원 브라우저에서는 앱처럼 설치해 전체 화면으로 실행할 수 있습니다.
- 설치 후에는 홈 화면 또는 데스크톱에서 바로 실행할 수 있으며, 기본 리소스는 오프라인에서도 동작합니다.
