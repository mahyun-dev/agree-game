# 이용약관에 동의하고 싶어

약관 동의 화면을 테마로 한 고난도 웹 퍼즐/호러 게임입니다.  
단순 체크박스에서 시작하지만, 스크롤 검증·도망가는 버튼·함정 선택지·기억 퍼즐까지 점점 어려워지는 구조로 구성되어 있습니다.

## 배포 주소 (GitHub Pages)

- 👉 [여기를 클릭해 실행](https://mahyun-dev.github.io/agree-game/)

## 게임 설명

- 장르: 웹 퍼즐 + 심리/호러 연출
- 언어: 한국어 UI/텍스트 기반
- 플랫폼: 모바일/데스크톱 반응형 웹
- 플레이 규칙: 실수(오답/시간 초과/함정 선택) 시 처음부터 재시작

## 핵심 특징

- 점진 난이도 상승형 12스테이지
- 스테이지별 제한시간 HUD
- 스크롤 기반 검증, 입력 퍼즐, 버튼 추적, 정렬 퍼즐, 시퀀스 퍼즐
- 시각/청각 연출(글리치, 경고 문구 전환, 진동/사운드)
- 최고 기록 저장(localStorage)

## 스테이지 개요

1. 시작 동의(필수 항목 체크)
2. 정밀 확인(약관 펼치기 + 정답 입력)
3. 긴 본문 스크롤 + 추가 검증
4. 이중 코드 입력
5. 도망가는 동의 버튼 포획
6. 제한 시간 집중 체크
7. 거대 함정 버튼 회피
8. 우선순위 정렬 퍼즐
9. 시스템 팝업 정리
10. 기억 시퀀스 입력
11. 미끼 약관 회피
12. 최종 동의(엔딩)
